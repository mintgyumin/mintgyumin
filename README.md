## 🚀 Key Projects

### 🤖 [JOYNER](https://github.com/AI-Joy-Assistant) — AI A2A 일정 자동 조율 서비스
> `2025.04 ~ 진행 중` | [🌐 joyner.co.kr](https://www.joyner.co.kr) | [📱 App Store: JOYNER](https://apps.apple.com/kr)

AI 에이전트 간 자율 협상(Agent-to-Agent)으로 다수 참여자의 일정을 자동 조율하는 iOS/Web 서비스.
사용자가 조건만 입력하면 AI가 최적 시간을 협상하고 Google Calendar에 자동 반영합니다.

- **문제 정의**: 기존 캘린더·조율 도구는 기록/공유 중심 — '자동 협상' 기능 부재
- **솔루션**: TimeSlot 알고리즘 + A2A 협상 구조로 후보 탐색 및 대안 제시 자동화
- **성과**: iOS 앱 정식 출시 완료 
- **스택**: `React Native(Expo)` `Next.js` `TypeScript` `Python` `OpenAI GPT-4` `Google Calendar API` `OAuth 2.0` `WebSocket`

---

### 🍽 [TASTE TRIP](https://github.com/SungshinChef/Web) — 재료 기반 레시피 추천 서비스
> `2025.03 ~ 2025.06`

사용자가 보유한 재료와 식단/알레르기 조건을 입력하면 매칭률 기반으로 레시피를 자동 탐색·추천하는 서비스.

- **문제 정의**: 기존 레시피 앱은 정보는 많지만, 현재 상황 반영한 탐색 구조 부재
- **솔루션**: 재료 입력 → 조건 반영 → 추천 결과 제시 흐름 설계 / 매칭률 기반 우선순위 정렬
- **스택**: `React Native(Expo)` `TypeScript` `FastAPI` `Docker` `Supabase` `Spoonacular API` `DeepL API`
